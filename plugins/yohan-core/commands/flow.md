# 승인된 작업 진행

작업: **$ARGUMENTS**

1. 기존 대화와 필요한 코드에서 결과·승인 범위를 확인한다. 작은 작업에 별도 계획 승인이나 탐색·기획 에이전트를 추가하지 않는다.
2. 수정 위치·기대 동작·호환성·확인 방법이 정해지면 승인된 범위를 구현한다. 다른 작업자의 변경을 보존한다.
3. 변경에 필요한 직접 검사만 수행하고 같은 조건의 통과 결과를 재사용한다. VHK는 문제 해결과 사용자 재개 승인 전까지 전면 보류한다. critic·cross-check·release-gate·Evaluator·자동 모델 검토를 연쇄 호출하지 않는다.
4. 승인된 Git 반영과 개발용 반영 범위만 끝낸다. PR Ready·merge·배포·publish와 삭제·외부 전송·유료 확대의 사람 게이트를 유지한다.
5. 결과·실행한 확인·남은 범위를 짧게 보고한다. 검사 결과를 자동 QA 보고서·영수증·일지로 복제하지 않는다.
