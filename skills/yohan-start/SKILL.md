# 작업도우미 (입구 하나만)

영어 묶음 이름(Operator Pack 등)은 **말하지 말 것**.  
사장님이 기억할 것 = **이 스킬 하나** + 아래 갈래.

## 열리면 할 일
1. 한 줄로 갈래 묻기. 이미 「1」「지시문」 등으로 골랐으면 바로 2로.
2. 갈래는 **셋뿐**:

| 사장님 말/상황 | 갈래 | 다음에 |
|----------------|------|--------|
| 긴 생각·아이디어·막연함 | **지시문 만들기** | 아래 「지시문 만들기 분기」 |
| 집 와서 이어서 / 지금 뭐였지 | **상태 보기** | `session-card` |
| 노션에 메모 쌓였음 / 미정제 | **노션에서 가져오기** | `notion-inbox-pickup` |

3. 그 외는 한 줄만: 아침 머지→morning-merge-check / PR 시크릿→secret-pr-guard / 짧은 조사→research-brief / 환경 동기화→master-orchestrator  
4. 파일 목록·영어 이름 나열 금지. 한 채팅에 갈래 **하나**.

## 지시문 만들기 분기 (독푸딩 반영)
메시지에 아래가 있으면 **초안 공장(긴 플랜 구현)으로 들어가지 말 것**:
- `Plan (rejected)` / `D1`~`D10` 표가 잔뜩 / `우로보로스` / todos pending 잔치

대신:
1. 한 줄: 「이건 옛 회의록이야. 구현 대상 아님.」
2. 눈으로 보게: `.agents/operator/how-skills-work.html` 열기(또는 경로 안내) + 5줄 요약  
3. 원하면 이해용 지시문: `prompts/understand-skills-usage-prompt.md`  
4. 진짜 새 생각 덤프면 그때 `dump-gate` → (충분하면) `thought-to-prompt`

일반 긴 생각(플랜 UI 아님)만 dump-gate → thought-to-prompt.

```
작업도우미 — 이번엔: 지시문 만들기 | 상태 보기 | 노션에서 가져오기
```

