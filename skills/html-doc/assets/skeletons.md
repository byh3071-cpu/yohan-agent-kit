# 6종 뼈대 — 섹션 순서와 컴포넌트 배정

> 공통: 모든 종은 **히어로(결론 한 문장) → 본론 → 한계**로 끝난다.
> 컴포넌트 이름은 `base.css` 클래스와 1:1 대응한다.

---

## 개념 — 원리·구조를 이해시킨다

| 순서 | 내용 | 컴포넌트 |
|---|---|---|
| 1 | 히어로 = 이 구조를 한 문장으로 | `.hero` |
| 2 | 용어 대응표 (비유를 쓸 거면 **여기서만** 정의) | `table` |
| 3 | 구조 도식 — 무엇이 무엇 위에 있나 | `.layers` |
| 4 | 단계 — 순서가 실제로 정보일 때만 | `.acts` |
| 5 | 한 줄 요약 | `.fix.done` |

정의하지 않은 비유는 쓰지 않는다. 대응표에 없는 낱말이 본문에 나오면 실패다.

---

## 코드 — 명령·로그를 비개발자에게 설명한다

| 순서 | 내용 | 컴포넌트 |
|---|---|---|
| 1 | 히어로 = 이 명령이 하는 일 한 문장 | `.hero` |
| 2 | 터미널 블록 (실제 입력·출력 그대로) | `.term` |
| 3 | 줄별 해설 — 왼쪽에 줄, 오른쪽에 뜻 | `table` |
| 4 | 실패하면 어떻게 보이나 | `.fix` |
| 5 | 한계 | `.foot` |

명령을 요약하거나 예쁘게 고치지 않는다. 붙여넣어 그대로 돌아가야 한다.

---

## 리서치 — 조사 결과를 근거와 함께 전한다

| 순서 | 내용 | 컴포넌트 |
|---|---|---|
| 1 | 히어로 = 조사가 뒤집은 것 한 문장 | `.hero` |
| 2 | 핵심 수치 3~4개 | `.cards` |
| 3 | 주장 ↔ 실측 대조 | `table` |
| 4 | 크기 비교가 논지면 막대 | `.rows` |
| 5 | 출처 목록 — **URL 전문** | `.foot` |

출처 없는 수치는 싣지 않는다. 확인 못 한 것은 `[미검증]`으로 남긴다.

---

## 점검 — 검사 결과를 보고한다

| 순서 | 내용 | 컴포넌트 |
|---|---|---|
| 1 | 히어로 = 판정 (통과 / 실패 / 조건부) | `.hero` |
| 2 | 항목별 판정·세부·소요 | `table` |
| 3 | 실패·경고 상세 | `.fix` |
| 4 | 다음 한 가지 | `.acts` (1개만) |
| 5 | 검사하지 않은 범위 | `.foot` |

"다음 한 가지"는 하나다. 둘 이상이면 우선순위를 못 정한 것이다.

---

## 결정 — 선택지를 비교해 고르게 한다

| 순서 | 내용 | 컴포넌트 |
|---|---|---|
| 1 | 히어로 = 추천안과 이유 한 문장 | `.hero` |
| 2 | 선택지 카드 — 각 카드에 **얻는 것 / 치르는 값** | `.cards` |
| 3 | 축별 대조 | `table` |
| 4 | 되돌리기 비용 | `.fix.hold` |
| 5 | 결론 + 언제 재검토하나 | `.acts` |

되돌리기 비용을 안 적은 결정 문서는 반쪽이다.

## 컴포넌트 고르는 법

| 논지 | 쓸 것 |
|---|---|
| 크기·기간·비용을 비교한다 | `.rows` 막대 |
| 있음 / 없음이 대비된다 | `.layers` 벽돌 vs `0` |
| 서로 다른 단위의 숫자 3~4개 | `.cards` |
| 같은 축으로 여러 행을 대조한다 | `table` |
| 순서가 정보다 | `.acts` 번호 카드 |
| 정정·경고·한계 | `.fix` |

**표는 문서당 2개 이하.** 3개째가 필요하면 그중 하나는 도식으로 바꿀 수 있다는 신호다.
